# Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| Space | Play or pause |
| J | Previous sentence |
| K | Next sentence |
| P | Previous item |
| N | Next item |
| , | Seek backward by selected interval |
| . | Seek forward by selected interval |
| F | Toggle focus mode |
| ? | Toggle shortcuts overlay |
| Ctrl/Command K | Open command menu |
| Enter on queue item | Play item |
