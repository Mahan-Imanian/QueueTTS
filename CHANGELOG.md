# Changelog

## 2.4.0

- Settings page reorganised into sections with a sticky side menu.
- Pronunciation rules are edited as a list (add, edit, delete, test) instead of a raw text box. The text box is still available under Advanced.
- Test-voice button and live values for rate, pitch and volume.
- Clearing all data moved into its own section with a stronger confirmation.
- The popup queue preview no longer repeats the item that is playing.

## 2.3.0

- Popup rebuilt as a fixed-width remote. Capture is the main action when the queue is empty, and the player only appears once something is queued.
- Queue rows show the source site, and failed captures show what went wrong with Review and Retry actions.
- Side panel uses a two-column layout when opened in a wide tab.

## 2.2.0

- First Chrome extension release, replacing the earlier web app: popup, side panel, settings page, context menus, page and selection capture, local storage.
